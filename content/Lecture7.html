Introduction

We have everything the photons need. Lecture 1 gave the temperature structure; Lecture 2 the populations; Lecture 3 the continuous opacity; Lectures 4–5 the line opacity. What remains is to let the light out: to solve the radiative transfer equation for the intensity that emerges from the top of the atmosphere, wavelength by wavelength. That emergent flux is the spectrum.

The physics is a single first-order equation, and in LTE it has a closed-form formal solution — the emergent flux is a weighted average of the source function over depth, with the weighting set by how the optical depth builds up. We will write that solution, evaluate it on the opacity we assembled, and watch a forest of iron lines appear exactly where the line list said they would. This is the lecture where the whole pipeline pays off: a synthetic solar spectrum, built from TeffT_{\rm eff}Teff​ and log⁡g\log glogg, matching the production code to a part in a thousand.

The transfer equation and its formal solution

Along a ray at angle θ\thetaθ to the surface normal (μ=cos⁡θ\mu = \cos\thetaμ=cosθ), the specific intensity obeys the plane-parallel transfer equation

μ dIλdτλ=Iλ−Sλ,\mu\,\frac{dI_\lambda}{d\tau_\lambda} = I_\lambda - S_\lambda,μdτλ​dIλ​​=Iλ​−Sλ​,

where τλ\tau_\lambdaτλ​ is the monochromatic optical depth measured inward and SλS_\lambdaSλ​ is the source function — the ratio of emission to absorption. In local thermodynamic equilibrium with negligible scattering, the source function is simply the Planck function at the local temperature, Sλ=Bλ(T)S_\lambda = B_\lambda(T)Sλ​=Bλ​(T), the result we have leaned on since Lecture 1.

This equation integrates exactly. The intensity emerging at the surface (τ=0\tau=0τ=0) along direction μ\muμ is the source function summed along the ray, weighted by the attenuation back to the surface,

Iλ(0,μ)=∫0∞Sλ(τλ) e−τλ/μ dτλμ.I_\lambda(0, \mu) = \int_0^\infty S_\lambda(\tau_\lambda)\,e^{-\tau_\lambda/\mu}\,\frac{d\tau_\lambda}{\mu}.Iλ​(0,μ)=∫0∞​Sλ​(τλ​)e−τλ​/μμdτλ​​.

The flux is this intensity integrated over the outward hemisphere. Carrying out the angle integral turns the exponential into the second exponential integral E2(τ)=∫1∞t−2e−τt dtE_2(\tau) = \int_1^\infty t^{-2}e^{-\tau t}\,dtE2​(τ)=∫1∞​t−2e−τtdt, giving the compact result

Fλ=2π∫0∞Sλ(τλ) E2(τλ) dτλ.F_\lambda = 2\pi \int_0^\infty S_\lambda(\tau_\lambda)\,E_2(\tau_\lambda)\,d\tau_\lambda .Fλ​=2π∫0∞​Sλ​(τλ​)E2​(τλ​)dτλ​.

The flux is a weighted average of the source function over depth, and the weight E2(τ)E_2(\tau)E2​(τ) is sharply peaked near τ≈2/3\tau \approx 2/3τ≈2/3 — the Eddington–Barbier depth of Lecture 1. We see, at each wavelength, the source function at τλ≈2/3\tau_\lambda \approx 2/3τλ​≈2/3; where a line spikes the opacity, that surface rises into cooler gas and the flux drops.

From opacity to optical depth

To use the formal solution we need the optical-depth scale at every wavelength. Optical depth accumulates the extinction (absorption plus scattering) along the column, and because our opacities are per gram, the integral is over the column mass ρx\rho xρx (RHOX) we have carried since Lecture 1:

τλ(ρx)=∫0ρx[κλabs+κλscat] d(ρx′).\tau_\lambda(\rho x) = \int_0^{\rho x} \big[\kappa^{\rm abs}_\lambda + \kappa^{\rm scat}_\lambda\big]\,d(\rho x').τλ​(ρx)=∫0ρx​[κλabs​+κλscat​]d(ρx′).

We build it by cumulative integration over depth, for the full opacity (continuum + lines) and for the continuum alone, so we can form both the line spectrum and the continuum it sits on.

def optical_depth(kappa):
    """Cumulative optical depth over column mass: tau[depth, wl]."""
    dtau = 0.5 * (kappa[1:] + kappa[:-1]) * np.diff(rhox)[:, None]     # trapezoid between layers
    tau = np.empty_like(kappa)
    tau[0] = kappa[0] * rhox[0]                                        # seed from the top layer
    tau[1:] = tau[0] + np.cumsum(dtau, axis=0)
    return tau

tau_line = optical_depth(total_abs + total_scat)     # full optical depth (continuum + lines)
tau_cont = optical_depth(cont_abs + cont_scat)        # continuum-only optical depth
print(f"at 505 nm, full optical depth spans {tau_line[:,2970].min():.1e} .. {tau_line[:,2970].max():.1e}")

The emergent flux

Now the formal solution. The source function is the Planck function at each depth and wavelength, Sλ=Bλ(T)S_\lambda = B_\lambda(T)Sλ​=Bλ​(T); we evaluate the flux integral Fλ=2π∫SλE2(τλ) dτλF_\lambda = 2\pi\int S_\lambda E_2(\tau_\lambda)\,d\tau_\lambdaFλ​=2π∫Sλ​E2​(τλ​)dτλ​ by summing over the depth grid, with a short from-scratch routine supplying E2E_2E2​ (the standard Abramowitz–Stegun rational approximation — no SciPy needed). Doing this for the full opacity gives the line spectrum; for the continuum alone, the continuum flux. Their ratio is the normalised spectrum — the rectified line depths that a spectroscopist actually measures, independent of the absolute flux calibration.

[3]Python 
def planck_nu(nu, T):
    x = H_C * nu / (K * T)
    return 1.47439e-2 * (nu/1e15)**3 * np.exp(-x) / (1.0 - np.exp(-x))

nu = C / (wl * 1e-7)                                   # frequency at each wavelength [Hz]
S = planck_nu(nu[None, :], T[:, None])                 # source function S = B(T): (depth, wl)

def expint2(x):
    """Second exponential integral E2(x) = exp(-x) - x*E1(x), from scratch (no SciPy).
    E1 via Abramowitz & Stegun 5.1.53 (x<=1) and 5.1.56 (x>1); E2(0)=1."""
    x = np.asarray(x, float)
    xp = np.where(x > 0.0, x, 1.0)                      # placeholder so log/division stay finite
    a = (-0.57721566, 0.99999193, -0.24991055, 0.05519968, -0.00976004, 0.00107857)
    e1_small = (a[0] + xp*(a[1] + xp*(a[2] + xp*(a[3] + xp*(a[4] + xp*a[5]))))) - np.log(xp)
    a1, a2, b1, b2 = 2.334733, 0.250621, 3.330657, 1.681534
    e1_large = np.exp(-xp)/xp * (xp*xp + a1*xp + a2) / (xp*xp + b1*xp + b2)
    E1 = np.where(x <= 1.0, e1_small, e1_large)
    return np.where(x > 0.0, np.exp(-x) - x*E1, 1.0)

def emergent_flux(tau):
    """F_lambda = 2*pi * integral S * E2(tau) over the optical-depth scale."""
    E2 = expint2(tau)                                  # second exponential integral (depth, wl)
    integrand = S * E2
    return 2*np.pi * np.trapezoid(integrand, tau, axis=0)

flux_line = emergent_flux(tau_line)
flux_cont = emergent_flux(tau_cont)
spectrum = flux_line / flux_cont                        # normalised (rectified) spectrum
reference = REF["flux_total"] / REF["flux_continuum"]
rel = np.abs(spectrum - reference) / reference
print(f"normalised spectrum vs reference:  median |rel diff| = {np.median(rel):.2e}   "

The Eddington–Barbier relation

The formal solution has a famous approximation. Because E2(τ)E_2(\tau)E2​(τ) weights the source function near τ≈2/3\tau \approx 2/3τ≈2/3, the emergent flux is close to π\piπ times the source function evaluated there:

Fλ≈π Sλ(τλ=2/3)=π Bλ(T(τλ=2/3)).F_\lambda \approx \pi\,S_\lambda(\tau_\lambda = 2/3) = \pi\,B_\lambda\big(T(\tau_\lambda = 2/3)\big).Fλ​≈πSλ​(τλ​=2/3)=πBλ​(T(τλ​=2/3)).

This is the Eddington–Barbier relation, and it is why a spectrum is a thermometer of depth: at each wavelength we read the temperature of the layer where that wavelength's optical depth reaches 2/32/32/3. In a line, the opacity is large, so τλ=2/3\tau_\lambda = 2/3τλ​=2/3 is reached higher up in cooler gas, and the flux is lower. Let us check the approximation against the full integral.

τ=2/3\tau=2/3τ=2/3 up into a higher, cooler layer, so the flux drops — the Eddington–Barbier picture.">

It makes the line-formation picture concrete: in a deep core the τ=2/3\tau=2/3τ=2/3 surface climbs to a layer hundreds — in the deepest cores, more than a thousand — kelvin cooler than the continuum-forming layer, and the Planck function, steeply temperature-sensitive in the blue, drops accordingly.

The one approximation left: scattering

The formal solution makes a single approximation: it takes the source function to be the Planck function, Sλ=BλS_\lambda = B_\lambdaSλ​=Bλ​. That is exact wherever true absorption dominates — almost everywhere — which is why the spectrum already matches to a part in a thousand. But in the very bottom of the deepest line cores, where the line opacity pushes τ=2/3\tau=2/3τ=2/3 up into the thin atmosphere, scattering (the Rayleigh and electron scattering of Lecture 3) becomes comparable to absorption, and the source function is pulled below the Planck function by photons that scatter and escape:

Sλ=κλabs Bλ+κλscat Jλκλabs+κλscat.S_\lambda = \frac{\kappa^{\rm abs}_\lambda\,B_\lambda + \kappa^{\rm scat}_\lambda\,J_\lambda}{\kappa^{\rm abs}_\lambda+\kappa^{\rm scat}_\lambda}.Sλ​=κλabs​+κλscat​κλabs​Bλ​+κλscat​Jλ​​.

This depends on the mean intensity JλJ_\lambdaJλ​, so it must be solved self-consistently with a Λ\LambdaΛ-iteration — and it deepens the cores by up to about ten percent. The production code does exactly this with its JOSH moment solver, and that solver is the subject of the next lecture: we rebuild it step by step and recover the spectrum to machine precision. The formal solution here gives the physics and the spectrum to a part in a thousand, and names precisely the one piece — scattering — that the exact engine adds.
